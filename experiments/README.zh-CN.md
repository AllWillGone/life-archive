# 系统实验

[English](README.md) | 简体中文

本目录保存 LifeArchive 的系统设计研究、提示词对照和模型行为评估，属于项目研究层，不属于自传式记忆层。

## 目录边界

- 实验条件、提示词、模型或客户端标签、测量方法、结果和技术结论写入本目录。
- 实验资料不写入 `fact/`、`feeling/`、`summary/` 或 `session/`，也不加入自传式索引和时间线。
- 普通自传式对话不默认读取本目录；只有当前任务涉及 LifeArchive 的设计、测试或维护时，才按需读取。
- 实验促成系统行为或目录职责变化时，证据保留在这里，实际发布变化记录到 `CHANGELOG.md`。

## 证据等级

| 等级 | 含义 | 最低要求 |
| --- | --- | --- |
| 探索性观察 | 在条件记录不完整或缺少控制时发现的有用行为 | 忠实保留观察，并明确所有重要限制 |
| 受控实验 | 使用固定夹具、已记录提示词与环境、重复运行和明确定义指标的对照 | 公开足够的脱敏材料，使他人可以重复流程 |
| 基准测试 | 用于跨版本稳定比较的版本化评估 | 增加经过验证的评分、代表性夹具、方差和变更控制 |

不得把探索性观察称为受控实验或基准测试。

## 公开安全要求

- 尽可能使用合成夹具；否则应充分移除直接和间接标识符，防止重新识别。
- 不公开原始私人聊天、真实记忆摘录、私有绝对路径、账户标识、未脱敏截图、认证秘密或未清理的模型输出。
- 记录第三方数据集、提示词或其他材料的来源和许可证；无法再分发的材料不得纳入仓库。
- 客户端显示的模型名称只能视为测试环境标签，除非同时记录了规范模型标识及其来源；不得从本地别名推断官方产品名称。
- 发布前检查文件名、暂存区差异、链接和 Git 历史；`.gitignore` 不能保护已经跟踪的文件。

## 记录要求

每份报告应在条件允许时包含：

- 目的与假设；
- 日期和相关的公开 LifeArchive commit 或发布版本；不得记录私人记忆仓库的 commit hash；
- 客户端、工具、模型标识、推理配置及各标签来源；
- 完整提示词或版本化协议；
- 合成测试夹具和初始上下文；
- 运行次数和重置流程；
- 指标定义和测量方法；
- 单次结果、汇总结果和方差；
- 局限、失败运行和缺失元数据；
- 结论以及由此产生的产品决定。

新实验使用[实验记录模板](experiment-template.zh-CN.md)。小型观察可以使用 `YYYY-MM-DD-主题.md` 单文件；包含提示词、夹具或原始结果的研究应使用独立目录。维护英文版本时，在对应英文报告旁保留 `.zh-CN.md` 中文版本。
