# Deprecated Support Extension

`support/` is not part of the default filing flow.

Ordinary assistant advice, action reminders, comfort, and in-the-moment supportive analysis stay in the conversation and are not written to the autobiographical memory directories. `session/` preserves the user's original messages, not assistant replies or memory-update summaries. Only wishes, decisions, actions, or results later expressed by the user are filed as new user-owned content according to `AGENTS.md`.

This compatibility placeholder remains for older clones only. New archives should not use it, agents should not read it during normal context construction, and it is not part of the repository layout documented for new installations.
