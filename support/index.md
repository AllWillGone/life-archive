# Deprecated Support Extension

`support/` is not part of the default filing flow.

Ordinary advice, action reminders, comfort, and in-the-moment supportive analysis may be summarized briefly in a `session` already warranted by user memory updates, or when the user explicitly asks to retain them. They do not become underlying memory. Only wishes, decisions, actions, or results later expressed by the user are filed as new user-owned content according to `AGENTS.md`.

This compatibility placeholder remains for older clones only. New archives should not use it, agents should not read it during normal context construction, and it is not part of the repository layout documented for new installations.
